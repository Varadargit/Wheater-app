# ⛅ Weather App

> Author: [Varadaraj](https://github.com/Varadargit)

The **Weather App** is a simple, responsive, and user-friendly web application that provides real-time weather updates for any location across the globe. It uses modern web technologies like **HTML**, **CSS**, and **JavaScript**, along with a weather API to fetch live weather data such as temperature, humidity, wind speed, and general conditions.

---

## 📌 Features

- 🔍 **Search by City/Location** using an intuitive input bar  
- 🌐 **Real-time Weather Data** for any city in the world  
- 📱 **Responsive Design** for mobile, tablet, and desktop views  
- 📊 Displays:
  - Temperature (°C/°F)
  - Humidity (%)
  - Wind Speed (km/h)
  - Weather Description (e.g., Cloudy, Sunny, Rainy)
- 🌍 **Current Location Support** using Geolocation API *(optional)*

---

## 🧪 Technologies Used

- **HTML5** – Structure and layout  
- **CSS3** – Styling and responsiveness  
- **JavaScript** – Interactivity and API integration  
- **OpenWeatherMap API** (or similar) – Real-time weather data

---

## ⚙️ How It Works

1. Users enter the name of a city in the search bar.
2. The app sends a request to the weather API with the entered location.
3. The API responds with current weather data.
4. The UI updates dynamically to show:
   - Temperature
   - Humidity
   - Wind speed
   - Weather conditions
5. Optionally, if location access is granted, the app can auto-fetch weather data for the user’s **current location**.
